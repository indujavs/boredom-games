# Little Break

A playful website with four mini-games to enjoy when you’re bored. Play against the computer and take a little break!

## Games

- **Tic-Tac-Toe** — try to get three Xs in a row.
- **Guess the Character** — identify a character from a clue. There are 20 different questions.
- **Rock, Paper, Scissors** — choose a move and play against the computer.
- **Heads or Tails** — call the coin flip.

## Play the website

Open the GitHub Pages link for this repository in your browser.

## Run it on your computer

1. Download or clone this repository.
2. Open `index.html` in a web browser.

## Files

- `index.html` — the page structure and game cards.
- `style.css` — colors, layout, and visual design.
- `script.js` — game rules and interactions.

Made as a beginner-friendly project while learning HTML, CSS, and JavaScript.
